GoonScroller

Open Reddit or X in this tab to use the buttons.

Auto-scroll: one post every 6s

Page keys

    Any key, no Ctrl/Alt needed. Works while the Reddit/X window is focused (not while you're typing). Click a key to change it; Backspace clears it, Esc cancels.

    Hotkeys

    The browser didn't assign the main hotkeys (maybe another extension uses them). Click Change hotkeys… and set them yourself.

      Set every key to Global there so it works while you're in a game. The browser doesn't let the extension do this for you.
