One step left: make the hotkeys Global

The browser doesn't let extensions switch this on themselves, so it takes 30 seconds by hand. Without it, the hotkeys only work while the browser window is focused.

  1. Click the button below to open the shortcuts page.
  2. Find GoonScroller. Give each action you want a key (click the pencil, press the keys).
  3. Set the dropdown next to every key to Global.
  4. Pick keys your game doesn't use, for example Ctrl+Shift+1/2/3/4 or Ctrl+Shift+arrow keys. Avoid Ctrl+W/A/S/D: Windows would grab them from your game and freeze your movement.

⚠️ A global hotkey stops working in every other program (games, Discord…) while the browser runs and GoonScroller is on. Closing Reddit/X or pausing doesn't free it; turning GoonScroller off in the extensions page does. League of Legends blocks global browser hotkeys completely.
